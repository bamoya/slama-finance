SLAMA AGRICOLE

Cinq e-mails, une même identité.

Blanc dominant, détails dorés et encarts couleur blé. Aperçus avec des données fictives, rendus par le moteur d’e-mails de l’application.

Utilisation

Dans Paramètres → Notifications, configurez la règle correspondante. Copiez l’objet ci-dessous, puis le contenu du fichier HTML dans « Code HTML ». Vérifiez l’aperçu, enregistrez et envoyez un test à votre adresse.

Gardez le mode HTML pour préserver cette mise en page. La conversion en édition visuelle peut simplifier les styles. Aucun paramètre ni aucune règle existante n’a été modifié.
